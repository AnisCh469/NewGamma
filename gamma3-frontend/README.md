## Installation

**Étape obligatoire après chaque nouveau clonage du dépôt** (ou après un `git pull` qui modifie `package.json`/`package-lock.json`) : les dépendances Node (`node_modules/`) ne sont jamais versionnées dans Git (voir `.gitignore`), il faut donc les installer localement avant de pouvoir lancer l'application.

```bash
npm install
```

Si un `ng serve` / `npm start` échoue avec une erreur du type `Cannot find module '.../node_modules/...'` ou `Could not resolve './fonts/...'` après un `npm install`, c'est le signe d'une installation précédente interrompue ou corrompue. Corrigez avec une réinstallation propre (supprime `node_modules/` et réinstalle exactement les versions verrouillées dans `package-lock.json`) :

```bash
npm ci
```
